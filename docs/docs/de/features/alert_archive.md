!!! Version note
    Diese Funktion wurde in Version 1.1.0 hinzugefügt und ist noch experimentell. 


FOSSWarn kann alte Warnmeldungen in einem lokalen Archiv speichern. Um diese Funktion zu aktivieren, gehe zu `settings` -> `enable alert archive`. 

Sobald dies aktiviert ist, wird jede neue Warnmeldung dauerhaft auf deinem Gerät gespeichert. Um das Archiv anzuzeigen, klicke auf `settings` -> `open archive`. 

!!! Warning
    FOSSWarn löscht Warnmeldungen nicht automatisch aus dem Archiv. Auf lange Sicht solltest du das Archiv daher gelegentlich leeren. Um alle Warnmeldungen aus dem Archiv zu löschen, drücke die Schaltfläche `Delete`.
