# FOSS Public Alert Server

Der FOSS Public Alert Server ist ein Gemeinschaftsprojekt von KDE und dem FOSSWarn-Team. Der Server aggregiert über 100 CAP-Warnquellen und ermöglicht es Clients, über UnifiedPush Push-Benachrichtigungen für abonnierte Gebiete zu empfangen. Erfahre mehr auf dem [GitLab des Projekts](https://invent.kde.org/webapps/foss-public-alert-server).

Der Server ist Open-Source-Software und kann bei Bedarf selbst gehostet werden. Wir stellen mit Hilfe von KDE den Standard-Server unter [alerts.kde.org](https://alerts.kde.org) bereit. Um den Server zu ändern, melde dich bitte von deinen Abonnements ab und ändere den Standard-Server in den Einstellungen.

Derzeit verfügbare Server sind: 

- [https://alerts.kde.org](https://alerts.kde.org) (von uns gepflegt und betrieben und immer in der neuesten Version)

- [https://alerts.adminforge.de](https://alerts.adminforge.de) (gepflegt von adminforge)


Wenn du die Standardkonfiguration des FOSS Public Alert Servers verwenden möchtest, kannst du bei den Standardeinstellungen bleiben.
