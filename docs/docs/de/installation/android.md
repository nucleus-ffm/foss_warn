# Android Installation


Du kannst FOSSWarn über eine der folgenden Optionen installieren: 

- [F-Droid](https://f-droid.org/de/packages/de.nucleus.foss_warn/) (empfohlen)
    F-Droid ist ein Android App Store für Open-Source-Anwendungen. Installiere einfach die F-Droid App von deren Webseite, suche nach "FOSSWarn" und drücke auf installieren.

- [GitHub](https://github.com/nucleus-ffm/foss_warn/releases) (nur für fortgeschrittene Nutzer)
    Jedes neue Release hat eine angehängte APK, die direkt installiert werden kann. Wenn du das GitHub-Release installierst, stelle bitte sicher, dass du regelmäßig auf neue Updates prüfst, da es keine automatischen Updates gibt. Um die App mit der GitHub-Version automatisch zu aktualisieren, schau dir bitte [Obtainium](https://github.com/ImranR98/Obtainium) an.
