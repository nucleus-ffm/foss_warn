!!! Warning
    Die Linux-Version ist noch experimentell und bietet nur begrenzten Support. 

FOSSWarn bietet eine experimentelle Linux-Version an, die für ARM- und x86-Geräte verfügbar ist. Sie wird noch nicht über einen Paketmanager verteilt und muss daher manuell installiert werden. Lade dazu die neueste FOSSWarn-Version für deine Linux-Plattform aus dem GitHub-Release herunter, entpacke die Datei und führe die ausführbare Datei aus. Zu einem späteren Zeitpunkt werden wir auch eine Flatpak-Version bereitstellen.
