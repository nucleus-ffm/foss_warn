# FOSS Public Alert Server

The FOSS Public Alert Server is a joint project of KDE and the FOSSWarn team. The server aggregates over 100 CAP alert sources and allows clients to receive push notifications via UnifiedPush for subscribed areas. Learn more on the [project's GitLab](https://invent.kde.org/webapps/foss-public-alert-server)

The server is open source software and can be self-hosted if desired. We provide the default Server with the help of KDE under [alerts.kde.org](https://alerts.kde.org). To change the server, please unsubscribe from your subscriptions and change the default server in the settings.

Currently available servers are: 

- [https://alerts.kde.org](https://alerts.kde.org) (maintained and operated by us and always the latest version)

- [https://alerts.adminforge.de](https://alerts.adminforge.de) (maintained by adminforge)


If you want to use the default FOSS Public Alert Server configuration, you can stick with the default settings.
