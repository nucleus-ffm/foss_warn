!!! Version note
    This feature has been added in version 1.1.0 and is still experimental. 


FOSSWarn can store old alerts in a local archive. To enable this feature, go to `settings` -> `enable alert archive`. 

As soon as this is enabled, every new alert will be stored permanently on your device. To view the archive, click `settings` -> `open archive`. 

!!! Warning
    FOSSWarn will not delete alerts from the archive automatically. So in the long run, you might want to clear the archive from time to time. To delete all alerts from the archive, press the `Delete` button.
