

<details>
<summary>How to change the notification sound?</summary>
Go to the app settings and press `open android notification settings` -> select the notification channel -> "Sound". This can variety for different android versions.
</details>

<details>
<summary>How do I receive notifications?</summary>
FOSS Warn uses UnifiedPush together with the FOSS Public Alert Server to receive push notifications. For more information about UnifiedPush please read https://github.com/nucleus-ffm/foss_warn/wiki/What-is-UnifiedPush-and-how-to-select-a-distributor
</details>

<details>
<summary>Do you have a custom F-Droid repo?</summary>
Yes, but you should prefer to download via F-Droid. Because of the extra work, the version in my repo is not the latest. You can add my custom repo to F-Droid and install the latest Github release with your F-Droid client. All info <a href="https://github.com/nucleus-ffm/Nucleus-F-Droid-Repo">here </a>.
</details>

<details>
<summary>In which languages is FOSSWarn available? There are some strange translations in the app</summary>
FOSSWarn is translated with the help of the community via <a href="https://hosted.weblate.org/projects/foss-warn/foss-warn-app/">Weblate</a>. The alerts themselves are in the languages in which they are published. If you would like to make an improvement, you can do so at any time on Weblate.
</details>

<details>
<summary>My language is not in the list. What can I do?</summary>
You can <a href="https://hosted.weblate.org/new-lang/foss-warn/foss-warn-app/">add a new language in Weblate</a> and start translating the app into your language  Please only start a new language if you really intend to translate it.
</details>

<details>
<summary>How can I receive update notifications for new versions when I use the APK from GitHub?</summary>
If you want to get a notification when we have released a new version, you should take a look at apps like <a href="https://github.com/ImranR98/Obtainium">Obtainium</a>.
</details>
