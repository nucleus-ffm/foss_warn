# 1.1.1 Remove non-free component

In version 1.1.0, we introduced the new dependency `geolocator`, which is used to retrieve the
current location. Unfortunately, the Android implementation contains a non-free component, 
which makes F-Droid unable to build it. So this release overrides the Android implementation 
with a fork that removed the non-free component. There is no other change, 
and the behavior should stay the same.
