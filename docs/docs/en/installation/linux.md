
!!! Warning
    The Linux version is still experimental and has limited support. 

FOSSWarn provides an experimental Linux version available for ARM and x86 devices. It is not yet distributed via package manager, so is has to be installed manually. For that download the latest FOSSWarn version for your linux platfrom from the GitHub release, extract the file and run executable. At some point in the future, we will also provide a flatpak version.
