# Android Installation


You can install FOSSWarn from one of the following options: 

- [F-Droid](https://f-droid.org/de/packages/de.nucleus.foss_warn/) (recommented)
    F-Droid is an Android app store for open source applications. Just install the F-Droid app from their website and search for "FOSSWarn" and press install.

- [GitHub](https://github.com/nucleus-ffm/foss_warn/releases) (for advanced users only)
    Every new release has an attached APK that can be directly installed. If you install the GitHub release, please ensure to regulary check for new updates as there will be no automatic updates. For automatically update the app with the GitHub version, please take a look at [Obtainium](https://github.com/ImranR98/Obtainium).
